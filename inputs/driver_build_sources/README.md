# Original-OSCAR driver construction sources

These sources comprise five reduced LUH3 regional products, their source reports and the historical atmospheric baseline used by `workflows/build_original_future_drivers.py`. `source_manifest.json` records their source and project-local location. The actual large raw LUH3 rasters are not duplicated here; their recorded provider receipts remain in the reduction reports. The large NetCDF inputs are distributed in `prepared_inputs.tar.gz`; the source catalogue and reduction reports are versioned here.
