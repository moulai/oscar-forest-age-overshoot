# Licence and source provenance

`LICENSE` is the upstream CeCILL free-software licence, version 2.1 (21 June 2013), retained unchanged with OSCAR. `VERSION` records v4-beta2. Existing copyright, author and licence notices in `oscar/`, `oscar_origin/` and copied preparation sources are retained. The forest-cohort extensions retain this code-licence context and the upstream attribution.

`oscar_origin/` is a separate importable copy of the original OSCAR reference, including the host fixes already recorded in its documentation. It is not the age-production-off H0 experiment. Preparation code copied into `inputs/preparation/` retains its original source and licence context; the source catalogue identifies the copied version.

Third-party data keep their own terms. LUH3 manifests preserve the provider's licence wording and its recorded CC BY 4.0 URL, including the wording inconsistency rather than silently relicensing the data. CMIP7 input4MIPs products retain provider/version/citation records; FRA2025 retains FAO attribution and terms; ESA CCI records its own terms; GAMI retains its documented source identity. The code licence is not a blanket data licence.

The original project-supplied 500-member file is delivered unchanged in `inputs/ensemble/`. Its recorded provenance gives the provider/model metadata and original digest but does not supply a separate data licence or generation method. The ensemble is provided unchanged, without regeneration or resampling, with its complete joint variables and ordered source IDs.
