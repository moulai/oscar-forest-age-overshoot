# Data release assets

The public v1.0.0 assets are available at https://github.com/moulai/oscar-forest-age-overshoot/releases/tag/v1.0.0.

- `prepared_inputs.tar.gz`: labelled prepared inputs, upstream runtime resources and source/licence metadata.
- `paper_source_data.tar.gz`: current figure and Supplementary Source Data, compact paired summaries and nine English captions.

Extract both archives at the checkout root. `reproduction/data_artifacts.json` records archive sizes and SHA-256 digests; the corresponding `*_files.json` inventories and the `*_DATA_MANIFEST.json` inside each archive record relative paths, file sizes and individual digests.
