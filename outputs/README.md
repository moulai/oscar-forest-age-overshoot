# Scientific data and outputs

The data assets are extracted at the repository root. `prepared_inputs.tar.gz` populates the historical input directories in `data/processed/`, the prepared CMIP7 and observation directories in `outputs/01_prepared_data/`, the upstream OSCAR resources and the optional conditional-growth inputs. `paper_source_data.tar.gz` populates the nine figure Source Data packages, compact paired core analysis and supplementary sensitivity sources.

`reproduction/paper_assets.json` maps the four main and five Extended Data figures. `reproduction/source_data_index.md` maps Supplementary Tables 1–15. Current English captions and the small architecture table are included in Git; numerical data and generated graphics are excluded.

Figure commands write to `outputs/reproduced/figures/`. Explicit analysis and model recipes have their own output roots and dependencies in `reproduction/commands.json`. The full simulation trajectory archive is generated by the model recipes and is separate from the compact Source Data asset.

Download links, sizes, file inventories and archive digests are in `reproduction/data_artifacts.json`. Dataset provenance and provider terms are described in `reproduction/DATA_PROVENANCE.md` and retained with the prepared-input asset.
