# Source material for ED1

`architecture_connections.csv` maps each displayed process to the implementation. `implementation_excerpts.md` contains the supporting source excerpts. `source_manifest.json` records the source paths and line ranges.

No synthetic quantitative data are used. Cohort cards illustrate stored birth/area/W/F state, not land-area proportions or a spatial grid. Arrows show selected routes and dependencies, with no flux-width scale. Primary is unaged; nonforest has no forest age. Standing secondary harvest retains its source birth time and area while routing removed carbon. Carbon pools CWD/soil/HWP are biome-supported, not birth-resolved.

The production reference is host environmental production split by fixed-calibration allocation. The formal age factors use gW=S+Sprime/lambda_w_cal and gF=1-exp(-age/2). The latter is a prescribed two-year establishment setting, not independently established global nonwoody NPP. gW need not be below one. F is other living tissue, not leaves alone. Age off sets factors to one while state, events and environmental responses continue.

D_Fland-D_Eluc is an all-native-land net-uptake anomaly relative to the declared PI baseline, excluding permafrost. It is not an age-specific forest NBP. The unit-area biome reference supports bookkeeping and is not another actual inventory. CO2 also exchanges with the ocean and other native channels. Effective forcing includes non-CO2 components; the schematic does not assign causal temperature shares. Experiment forcing can prescribe individual concentrations or environmental variables.
