# Source Data for ED4

The compact original core tables retain all five conditions and 500 paired IDs each. No whole annual member cube is copied. density_bin_shares.csv adds ensemble_share_pct = 100 * original_member_count / 500 to the same 10 mK by one-year bins. Empty bins are transparent; the shared colour coordinate is logarithmic, with actual percentage ticks. H/M window-end maxima are not resolved physical peaks; all state/left-truncation/censoring flags remain. Empirical parameter distributions are not scenario-weighted probabilities or confidence intervals.
